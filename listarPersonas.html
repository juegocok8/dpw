ArrayList & Sesiones en JSP

Laboratorio · registro de personas en memoria

Java HttpSession
Objetivo

Desarrollar una aplicación web en JSP que permita registrar personas en memoria utilizando un ArrayList<Persona> almacenado en la sesión (HttpSession). Comprender cómo mantener información entre distintas páginas sin utilizar una base de datos.

Enunciado del ejercicio

Construya una aplicación web utilizando JSP y JavaBeans que permita registrar personas con los siguientes atributos:

DUI Nombres Apellidos Dirección

Cada registro se almacena en un ArrayList<Persona> guardado en la sesión del usuario. La aplicación consta de dos páginas:

  • agregar.jsp: formulario para ingresar una nueva persona.
  • index.jsp: muestra el listado de personas almacenadas.
  • guardar.jsp: recibe los datos crea la sesión .

Clase Persona, creala dentro del paquete clases

public class Persona implements java.io.Serializable { private String dui; private String nombres; private String apellidos; private String direccion; public Persona() {} public Persona(String dui, String nombres, String apellidos, String direccion) { this.dui = dui; this.nombres = nombres; this.apellidos = apellidos; this.direccion = direccion; } // Getters public String getDui() { return dui; } public String getNombres() { return nombres; } public String getApellidos() { return apellidos; } public String getDireccion() { return direccion; } }

guardar.jsp

<%@page import="java.util.ArrayList"%> <%@page import="clases.Persona"%> <% ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas"); if(lista == null) { lista = new ArrayList<>(); } Persona p = new Persona( request.getParameter("dui"), request.getParameter("nombres"), request.getParameter("apellidos"), request.getParameter("direccion") ); lista.add(p); session.setAttribute("personas", lista); response.sendRedirect("index.jsp"); %>

Operaciones con la sesión

Obtener / crear lista
ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas"); if(lista == null) { lista = new ArrayList<>(); }
Guardar
lista.add(p); session.setAttribute("personas", lista);
Recuperar
ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas");
Cerrar sesión
session.invalidate();

Flujo de la aplicación

  1. 0 El Usuario ejecuta la página   index.jsp, colocamos un botón para llamar al formulario agregar.jsp
  2. 1 Usuario llena el formulario en  agregar.jsp, al guardar la información llama a la página guardar.jsp
  3. 2 guardar.jsp   recibe los datos y crea un objeto  Persona.
  4. 3 Si el  ArrayList  no existe en sesión, se crea uno nuevo.
  5. 4 Se agrega la nueva  Persona  a la lista.
  6. 5 La lista se guarda en la sesión con  session.setAttribute(...).
  7. 6 Se redirige a  index.jsp , que recupera la lista y la muestra.

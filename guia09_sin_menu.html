📚 Guía Fullstack Paso a Paso: Spring Boot + React (Vite)

Construcción de la API REST y Consumo desde Frontend para la Gestión de Marcas

☕ Java / Spring Boot ⚛️ React + TypeScript 🗄️ MySQL ⚡ Vite

Esta guía documenta el orden cronológico y arquitectónico completo para construir el sistema Fullstack:

1. Backend (Spring Boot + JPA + MySQL): Desde la base de datos hasta el controlador REST.
2. Frontend (React + TypeScript + Vite): Desde la creación del proyecto con Vite hasta el componente ConsultaAgregaMarca.tsx y su ejecución en el navegador.

Objetivos

  • Crear la base de datos física y la tabla donde se almacenarán las marcas.
  • Establecer la conexión JDBC y el dialecto de Hibernate.
  • Mapear la tabla marcas a una clase Java gestionada por JPA.
  • Proveer operaciones CRUD y métodos de búsqueda automáticamente.
  • Aplicar la lógica de negocio y gestionar la transaccionalidad.
  • Recibir peticiones HTTP y devolver respuestas en formato JSON.
  • Crear un componente minimalista que solo consulte (GET) y agregue (POST) marcas, sin validaciones complejas.

  • created_at: Marca temporal asignada por defecto por MySQL (CURRENT_TIMESTAMP).

🔵 Entidad y Mapeo Objeto-Relacional

src/main/java/com/example/autosPRO/entity/Marca.java

Objetivo: Mapear la tabla marcas a una clase Java gestionada por JPA.

Marca.javajava
package com.example.autosPRO.entity;

import com.fasterxml.jackson.annotation.JsonFormat;
import com.fasterxml.jackson.annotation.JsonIgnore;
import jakarta.persistence.*;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;

@Entity
@Table(name = "marcas")
public class Marca {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    @Column(name = "nombre", nullable = false, length = 100)
    private String nombre;

    @Column(name = "created_at", updatable = false)
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private LocalDateTime createdAt;

    @JsonIgnore
    @OneToMany(mappedBy = "marca", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<Modelo> modelos = new ArrayList<>();

    public Marca() {
    }

    public Marca(Integer id, String nombre) {
        this.id = id;
        this.nombre = nombre;
    }

    @PrePersist
    public void prePersist() {
        if (this.createdAt == null) {
            this.createdAt = LocalDateTime.now();
        }
    }

    // Getters y Setters
    public Integer getId() { return id; }
    public void setId(Integer id) { this.id = id; }

    public String getNombre() { return nombre; }
    public void setNombre(String nombre) { this.nombre = nombre; }

    public LocalDateTime getCreatedAt() { return createdAt; }
    public void setCreatedAt(LocalDateTime createdAt) { this.createdAt = createdAt; }

    public List<Modelo> getModelos() { return modelos; }
    public void setModelos(List<Modelo> modelos) { this.modelos = modelos; }
}
  • @Entity y @Table(name = "marcas"): Define la clase como entidad JPA vinculada a la tabla.
  • @Id y @GeneratedValue(strategy = GenerationType.IDENTITY): Clave primaria autoincrementable.
  • @Column: Enlaza los atributos con sus columnas correspondientes.
  • @JsonIgnore: Evita la recursión infinita en la serialización JSON con Modelo.

🟣 Repositorio Spring Data JPA

src/main/java/com/example/autosPRO/repository/MarcaRepository.java

Objetivo: Proveer operaciones CRUD y métodos de búsqueda automáticamente.

package com.example.autosPRO.repository;

import com.example.autosPRO.entity.Marca;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

import java.util.List;

@Repository
public interface MarcaRepository extends JpaRepository<Marca, Integer> {
    List<Marca> findByNombreContainingIgnoreCase(String nombre);
}
  • JpaRepository<Marca, Integer>: Otorga métodos preconstruidos: findAll(), findById(), save(), deleteById().
  • findByNombreContainingIgnoreCase: Consulta derivada que genera un LIKE %nombre% automático.

5.2. Implementación del Servicio

MarcaServiceImpl.javajava
package com.example.autosPRO.service.impl;

import com.example.autosPRO.entity.Marca;
import com.example.autosPRO.repository.MarcaRepository;
import com.example.autosPRO.service.MarcaService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.Optional;

@Service
@Transactional
public class MarcaServiceImpl implements MarcaService {

    private final MarcaRepository marcaRepository;

    @Autowired
    public MarcaServiceImpl(MarcaRepository marcaRepository) {
        this.marcaRepository = marcaRepository;
    }

    @Override
    @Transactional(readOnly = true)
    public List<Marca> findAll() {
        return marcaRepository.findAll();
    }

    @Override
    @Transactional(readOnly = true)
    public Optional<Marca> findById(Integer id) {
        return marcaRepository.findById(id);
    }

    @Override
    @Transactional(readOnly = true)
    public List<Marca> findByFiltros(String nombre) {
        if (nombre != null && !nombre.trim().isEmpty()) {
            return marcaRepository.findByNombreContainingIgnoreCase(nombre.trim());
        }
        return marcaRepository.findAll();
    }

    @Override
    public Marca save(Marca marca) {
        return marcaRepository.save(marca);
    }

    @Override
    public Marca update(Integer id, Marca marcaDetails) {
        return marcaRepository.findById(id).map(marca -> {
            marca.setNombre(marcaDetails.getNombre());
            return marcaRepository.save(marca);
        }).orElseThrow(() -> new RuntimeException("Marca no encontrada con id: " + id));
    }

    @Override
    public boolean deleteById(Integer id) {
        if (marcaRepository.existsById(id)) {
            marcaRepository.deleteById(id);
            return true;
        }
        return false;
    }
}
  • @Service: Registra el componente de servicio.
  • @Transactional(readOnly = true): Optimiza el rendimiento en operaciones de lectura.

🔴 Controlador REST

src/main/java/com/example/autosPRO/controller/MarcaRestController.java

Objetivo: Recibir peticiones HTTP y devolver respuestas en formato JSON.

MarcaRestController.javajava 
package com.example.autosPRO.controller;

import com.example.autosPRO.entity.Marca;
import com.example.autosPRO.service.MarcaService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/marcas")
@CrossOrigin(origins = "*")
public class MarcaRestController {

    private final MarcaService marcaService;

    @Autowired
    public MarcaRestController(MarcaService marcaService) {
        this.marcaService = marcaService;
    }

    // Endpoint GET: Consultar todas las marcas
    @GetMapping
    public ResponseEntity<List<Marca>> getAll(@RequestParam(required = false) String buscar) {
        return ResponseEntity.ok(marcaService.findByFiltros(buscar));
    }

    // Endpoint POST: Registrar una nueva marca
    @PostMapping
    public ResponseEntity<?> create(@RequestBody Marca marca) {
        if (marca.getNombre() == null || marca.getNombre().trim().isEmpty()) {
            return ResponseEntity.badRequest().body("El nombre de la marca es obligatorio");
        }
        Marca saved = marcaService.save(marca);
        return ResponseEntity.status(HttpStatus.CREATED).body(saved);
    }
}
  • @RestController: Serializa automáticamente las respuestas a JSON.
  • @CrossOrigin(origins = "*"): Permite peticiones desde el frontend de Vite (http://localhost:5173).
  • @GetMapping: Responde a GET /api/marcas.
  • @PostMapping: Responde a POST /api/marcas recibiendo el JSON { "nombre": "..." }.

🧩 Creación del Componente ConsultaAgregaMarca.tsx

front2/src/components/ConsultaAgregaMarca.tsx

Objetivo: Crear un componente minimalista que solo consulte (GET) y agregue (POST) marcas, sin validaciones complejas.

ConsultaAgregaMarca.tsxtsx
// 1. Importamos los hooks necesarios y el tipo de evento de React
import { useEffect, useState, type FormEvent } from 'react';

// 2. Definimos la estructura del objeto Marca (coincide con el backend)
interface Marca {
  id: number;
  nombre: string;
  createdAt?: string;
}

// 3. Componente funcional mínimo (Solo Consultar y Agregar)
export const ConsultaAgregaMarca = () => {
  // 4. Estados locales: lista de marcas y valor del campo de texto
  const [marcas, setMarcas] = useState<Marca[]>([]);
  const [nombre, setNombre] = useState<string>('');

  // 5. Función para consultar las marcas desde el backend (GET)
  const cargarMarcas = () => {
    fetch('http://localhost:8080/api/marcas')
      .then((res) => res.json())
      .then((data) => setMarcas(data));
  };

  // 6. useEffect: Se ejecuta una sola vez al cargar el componente
  useEffect(() => {
    cargarMarcas();
  }, []);

  // 7. Función para agregar una marca al backend (POST)
  const agregarMarca = (e: FormEvent) => {
    e.preventDefault(); // Evita que se recargue la página al enviar el formulario

    fetch('http://localhost:8080/api/marcas', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ nombre }),
    })
      .then((res) => res.json())
      .then(() => {
        setNombre('');     // Limpiamos el campo de texto
        cargarMarcas();   // Refrescamos la tabla con el nuevo registro
      });
  };

  // 8. Renderizado del formulario y la tabla
  return (
    <div style={{ padding: '20px' }}>
      <h2>Consulta y Registro de Marcas</h2>

      {/* Formulario simple para agregar */}
      <form onSubmit={agregarMarca} style={{ marginBottom: '15px' }}>
        <input
          type="text"
          placeholder="Nombre de la marca"
          value={nombre}
          onChange={(e) => setNombre(e.target.value)}
        />
        <button type="submit" style={{ marginLeft: '10px' }}>
          Agregar
        </button>
      </form>

      {/* Tabla simple para listar */}
      <table cellPadding={8} style={{ width: '100%', borderCollapse: 'collapse', color: 'blue' }}>
        <thead>
          <tr>
            <th>ID</th>
            <th>Nombre</th>
            <th>Fecha de Creación</th>
          </tr>
        </thead>
        <tbody>
          {marcas.map((m) => (
            <tr key={m.id}>
              <td>{m.id}</td>
              <td>{m.nombre}</td>
              <td>{m.createdAt || 'Sin fecha'}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
};

export default ConsultaAgregaMarca;

Explicación de los bloques del componente:

  1. interface Marca: Define el contrato de datos esperado (id, nombre, createdAt).
  2. useState<Marca[]>([]): Almacena el arreglo de marcas recibidas del backend.
  3. useState<string>(''): Controla en tiempo real el valor del <input> mediante two-way binding.
  4. cargarMarcas(): Ejecuta fetch('http://localhost:8080/api/marcas') con método GET por defecto.
  5. useEffect(..., []): Hook de ciclo de vida que dispara cargarMarcas() tras el primer render.
  6. agregarMarca(): Envía el objeto JSON { nombre } mediante POST con cabecera Content-Type: application/json. Tras completarse, limpia el input y recarga la tabla.

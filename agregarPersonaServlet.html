ArrayList & Sesiones con Servlet

Laboratorio · registro de personas usando MVC con Servlet + Bootstrap 5

Java Servlet HttpSession
Objetivo

Desarrollar una aplicación web que permita registrar personas en memoria utilizando un ArrayList<Persona> almacenado en la sesión (HttpSession). La lógica de negocio se implementa mediante un Servlet siguiendo el patrón MVC, separando la vista (JSP) del controlador. Las vistas utilizan Bootstrap 5 para un diseño moderno y responsivo.

Enunciado del ejercicio

Construya una aplicación web utilizando Servlets, JSP y JavaBeans que permita registrar personas con los siguientes atributos:

DUI Nombres Apellidos Dirección

Cada registro se almacena en un ArrayList<Persona> guardado en la sesión del usuario. La aplicación consta de:

  • index.jsp: vista principal que muestra el listado de personas (con Bootstrap).
  • agregar.jsp: formulario para ingresar una nueva persona (con Bootstrap).
  • PersonaServlet: controlador que procesa las peticiones (guardar, listar, eliminar).
  • Persona.java: Modelo.

package clases; public class Persona implements java.io.Serializable { private String dui; private String nombres; private String apellidos; private String direccion; public Persona() {} public Persona(String dui, String nombres, String apellidos, String direccion) { this.dui = dui; this.nombres = nombres; this.apellidos = apellidos; this.direccion = direccion; } // Getters y Setters public String getDui() { return dui; } public void setDui(String dui) { this.dui = dui; } public String getNombres() { return nombres; } public void setNombres(String nombres) { this.nombres = nombres; } public String getApellidos() { return apellidos; } public void setApellidos(String apellidos) { this.apellidos = apellidos; } public String getDireccion() { return direccion; } public void setDireccion(String direccion) { this.direccion = direccion; } }

PersonaServlet (Controlador)

package controladores; import java.io.IOException; import java.util.ArrayList; import javax.servlet.ServletException; import javax.servlet.annotation.WebServlet; import javax.servlet.http.HttpServlet; import javax.servlet.http.HttpServletRequest; import javax.servlet.http.HttpServletResponse; import javax.servlet.http.HttpSession; import clases.Persona; @WebServlet("/PersonaServlet") public class PersonaServlet extends HttpServlet { @Override protected void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { String action = request.getParameter("action"); HttpSession session = request.getSession(); if ("eliminar".equals(action)) { int index = Integer.parseInt(request.getParameter("index")); ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas"); if (lista != null && index >= 0 && index < lista.size()) { lista.remove(index); session.setAttribute("personas", lista); } response.sendRedirect("index.jsp"); return; } else if ("limpiar".equals(action)) { session.removeAttribute("personas"); response.sendRedirect("index.jsp"); return; } else if ("agregar".equals(action)) { response.sendRedirect("agregar.jsp"); return; } response.sendRedirect("index.jsp"); } @Override protected void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { String dui = request.getParameter("dui"); String nombres = request.getParameter("nombres"); String apellidos = request.getParameter("apellidos"); String direccion = request.getParameter("direccion"); if (dui == null || dui.trim().isEmpty() || nombres == null || nombres.trim().isEmpty() || apellidos == null || apellidos.trim().isEmpty() || direccion == null || direccion.trim().isEmpty()) { request.setAttribute("error", "Todos los campos son obligatorios"); request.getRequestDispatcher("agregar.jsp").forward(request, response); return; } HttpSession session = request.getSession(); ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas"); if (lista == null) { lista = new ArrayList<>(); } Persona p = new Persona(dui, nombres, apellidos, direccion); lista.add(p); session.setAttribute("personas", lista); response.sendRedirect("index.jsp"); } }

Operaciones con la sesión

Obtener / crear lista
ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas"); if(lista == null) { lista = new ArrayList<>(); }
Guardar en sesión
lista.add(persona); session.setAttribute("personas", lista);
Recuperar
ArrayList<Persona> lista = (ArrayList<Persona>) session.getAttribute("personas");
Eliminar de sesión
session.removeAttribute("personas"); // o session.invalidate() para cerrar toda la sesión

Flujo de la aplicación

  1. 1 El usuario accede a index.jsp, que muestra el listado de personas almacenadas en la sesión.
  2. 2 Hace clic en "Agregar nueva persona", que envía una petición GET a PersonaServlet?action=agregar y redirige a agregar.jsp.
  3. 3 Llena el formulario en agregar.jsp y envía (POST) a PersonaServlet.
  4. 4 El Servlet valida los campos y crea un objeto Persona.
  5. 5 Obtiene o crea el ArrayList desde la sesión y agrega la nueva persona.
  6. 6 Guarda la lista en la sesión con session.setAttribute("personas", lista).
  7. 7 Redirige a index.jsp, que recupera la lista actualizada y la muestra.
  8. 8 El usuario puede eliminar una persona (acción GET con action=eliminar) o limpiar toda la lista (action=limpiar).

🚀 Laboratorio #2 framework

Spring Boot & MVC

Laboratorio · desarrollo de aplicaciones web con Spring Boot, patrón MVC, persistencia con JPA y vistas con Thymeleaf

Spring Boot Spring MVC JPA / Hibernate Thymeleaf MySQL Maven

🎯 Objetivo

Desarrollar una aplicación web empresarial utilizando Spring Boot como framework principal, aplicando el patrón de arquitectura MVC para separar la lógica de negocio, el acceso a datos y la capa de presentación. La persistencia se gestionará con Spring Data JPA sobre una base de datos relacional, y las vistas se construirán con Thymeleaf integrando Bootstrap 5 para lograr un diseño moderno y responsivo. Todo el proyecto se estructurará con Maven siguiendo las buenas prácticas de Spring Boot.

✅ Objetivos específicos

  • Configurar un proyecto Spring Boot desde cero con Spring Initializr y Maven como gestor de dependencias.
  • Implementar el patrón MVC usando @Controller, @Service y @Repository en Spring Boot.
  • Modelar entidades con JPA / Hibernate y mapear relaciones entre tablas mediante anotaciones (@Entity, @OneToMany, @ManyToOne, @ManyToMany).
  • Desarrollar operaciones CRUD completas usando Spring Data JPA y repositorios derivados.
  • Construir la capa de presentación con Thymeleaf, fragmentos reutilizables y formularios con Spring Form Binding.
  • Aplicar validación de datos con Bean Validation (@Valid, @NotNull, @Size).
  • Implementar consultas personalizadas con JPQL, @Query y filtros dinámicos con Criteria API.
  • Diseñar un menú de navegación modular y responsivo con Bootstrap 5 y Thymeleaf Layouts.
  • Integrar una base de datos relacional (MySQL / PostgreSQL) y gestionar el esquema con application.properties.
  • Aplicar buenas prácticas: inyección de dependencias, capas desacopladas, DTOs y manejo global de excepciones con @ControllerAdvice.
